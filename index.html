Athena Automations - QA extension

Temporarily installs the QA build of Athena Automations by ElasticIT for the current test window. The only thing added to your computer is this extension - and it can be removed just as easily (below).

Install the QA extension

Download installer (athena-qa.reg)
  1. Double-click the downloaded athena-qa.reg and confirm.
  2. Quit Microsoft Edge completely (check Task Manager for msedge.exe) and start it again.
  3. Check edge://extensions - “QA | Athena Automations by ElasticIT” is installed.

Remove the QA extension (when testing ends)

Download remover (athena-qa-uninstall.reg)
  1. Double-click the downloaded athena-qa-uninstall.reg and confirm.
  2. Quit and restart Microsoft Edge - the QA extension uninstalls itself.

No admin rights required. The QA extension keeps itself up to date automatically while it is installed.
